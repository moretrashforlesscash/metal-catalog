# metal-catalog — контекст для Claude

## Кто владелец и зачем репо
Алем, B2B-поставщик металлопроката, Казахстан (Алматы). Репо — база товаров от поставщиков металла:
каталоги, ежедневные прайсы, расчёт цены, веса, габаритов и доставки до города клиента.
Общение — по-русски.

## Жёсткие правила ответа на запрос цены
1. Цену называть **только из `catalog/`**, с указанием: поставщик, дата прайса, исходная строка/артикул.
2. Если точной позиции нет — так и сказать. Не подставлять «похожую» молча; аналоги предлагать явно помеченными.
3. Вес считать по `scripts/weights.py` (формулы/таблицы ГОСТ), не «на глаз». Указывать, что вес теоретический (факт ±3–8%).
4. Доставку считать только по `logistics/tariffs.csv`. Нет направления — оценка по ставке ₸/км с явной пометкой «оценка».
5. Валюта — тенге (₸). НДС РК — 16% (Налоговый кодекс РК с 01.01.2026). Всегда явно писать, цена с НДС или без.
6. Числа считает код, не модель.

## Структура
- `suppliers/<поставщик>/raw/` — оригиналы прайсов (xlsx), имя файла = дата `YYYY-MM-DD.xlsx`
- `suppliers/<поставщик>/parser.py` — парсер формата конкретного поставщика → нормализованные строки
- `catalog/<поставщик>.csv` — нормализованный каталог (пересобирается полностью из свежего прайса)
- `reference/weights/` — таблицы масс по ГОСТ (уголок, швеллер, балка и т.д.)
- `logistics/tariffs.csv` — реальные ставки перевозчиков; `logistics/distances.csv` — расстояния
- `scripts/weights.py` — расчёт массы проката

## Схема нормализованного каталога (`catalog/*.csv`)
| поле | описание |
|---|---|
| supplier | поставщик |
| price_date | дата прайса YYYY-MM-DD |
| sku | артикул поставщика (если есть) |
| raw_name | исходное наименование как в прайсе |
| category | лист, труба_круглая, труба_профильная, уголок, швеллер, балка, арматура, круг, квадрат, полоса, ... |
| standard | ГОСТ/СТ РК/ТУ |
| grade | марка стали (Ст3сп, 09Г2С, AISI 304, ...) |
| dims | размеры в каноническом виде, мм (напр. `40x20x2`, `57x3.5`, `12П`, `d12`) |
| length_m | длина, м (пусто = мерная/немерная не указана) |
| unit | единица цены поставщика: т, м, шт, м2 |
| price | цена за unit, ₸ |
| vat_included | true/false |
| price_per_t | цена за тонну, ₸ (пересчёт) |
| mass_kg_m | теоретическая масса, кг/м (или кг/м² для листа) |

## Обновление прайса (план)
Скрипт скачивает xlsx → сохраняет в raw (если изменился) → парсер → проверки
(падение числа строк >20%, пропавшие колонки, скачок цены >30% — НЕ перезаписывать, слать тревогу) →
полная перезапись `catalog/<поставщик>.csv` → коммит → отчёт об изменениях цен.
