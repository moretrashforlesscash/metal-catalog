# metal-catalog — контекст для Claude

## Кто владелец и зачем репо
Алем, B2B-поставщик металлопроката, Казахстан (Алматы). Репо — база товаров от поставщиков металла:
каталоги, ежедневные прайсы, расчёт цены, веса, габаритов и доставки до города клиента.
Общение — по-русски.

## Как работаем с репо
- Claude коммитит и пушит **сразу в `main`**, без PR и без подтверждений — разрешено владельцем.
- Каждую задачу заканчивать пушем: контейнер сессии временный, незапушенное теряется.
- Объяснять владельцу простым языком, без жаргона.

## Жёсткие правила ответа на запрос цены
1. Цену называть **только из `catalog/`**, с указанием: поставщик, дата прайса, исходная строка/артикул.
2. Если точной позиции нет — так и сказать. Не подставлять «похожую» молча; аналоги предлагать явно помеченными.
3. Вес считать по `scripts/weights.py` (формулы/таблицы ГОСТ), не «на глаз». Указывать, что вес теоретический (факт ±3–8%).
4. Доставку считать только по `logistics/tariffs.csv`. Нет направления — оценка по ставке ₸/км с явной пометкой «оценка».
5. Валюта — тенге (₸). НДС РК — 16% (Налоговый кодекс РК с 01.01.2026). Всегда явно писать, цена с НДС или без.
6. Числа считает код, не модель.

## Структура
- `suppliers/<поставщик>/raw/` — оригиналы прайсов (xlsx), имя файла = дата `YYYY-MM-DD.xlsx`
- `suppliers/<поставщик>/parser.py` — парсер формата конкретного поставщика → нормализованные строки
- `catalog/<поставщик>.csv` — нормализованный каталог (пересобирается полностью из свежего прайса)
- `reference/weights/` — таблицы масс по ГОСТ (уголок, швеллер, балка и т.д.)
- `logistics/tariffs.csv` — реальные ставки перевозчиков; `logistics/distances.csv` — расстояния
- `scripts/weights.py` — расчёт массы проката

## Схема нормализованного каталога (`catalog/*.csv`)
| поле | описание |
|---|---|
| supplier | поставщик |
| price_date | дата прайса YYYY-MM-DD |
| sku | артикул поставщика (если есть) |
| raw_name | исходное наименование как в прайсе |
| category | лист, труба_круглая, труба_профильная, уголок, швеллер, балка, арматура, круг, квадрат, полоса, ... |
| standard | ГОСТ/СТ РК/ТУ |
| grade | марка стали (Ст3сп, 09Г2С, AISI 304, ...) |
| dims | размеры в каноническом виде, мм (напр. `40x20x2`, `57x3.5`, `12П`, `d12`) |
| length_m | длина, м (пусто = мерная/немерная не указана) |
| unit | единица цены поставщика: т, м, шт, м2 |
| price | цена за unit, ₸ |
| vat_included | true/false |
| price_per_t | цена за тонну, ₸ (пересчёт) |
| mass_kg_m | теоретическая масса, кг/м (или кг/м² для листа) |

## Поставщики
### Металл Сервис (mc.ru), Москва — `suppliers/metallservis/`
- Источник: https://mc.ru/price/msk → «Загрузить общий прайс лист» → zip из 10 xls
  (cvetmet, engineering, kachestvst, krepezh, listovojprokat, metizy, nerzhaveika, profnastil, sortovojprokat, truby).
- Цены в **рублях, с российским НДС**. Для Казахстана нужен пересчёт (курс ₽→₸, НДС РФ → НДС РК 16%, доставка из Москвы).
- Ед. изм.: `т`, `теор.т` (по теоретическому весу), `кг`, `шт`, `тыс.шт`, `м`, `м2`. Сортовой прокат — «цена от 5 т».
- В xls нет различающих признаков у дублей (одна марка/размер — несколько цен: разные заводы/длины).
  У швеллера нет серии П/У. Подробности есть только в HTML-версии на сайте.
- Обновить: положить xls в `suppliers/metallservis/raw/ГГГГ-ММ-ДД/` и запустить
  `python3 suppliers/metallservis/parser.py suppliers/metallservis/raw/ГГГГ-ММ-ДД` → `catalog/metallservis.csv`.
- mc.ru **обрывает соединения с зарубежных IP** (облако Claude выходит из США) — автоскачивание только с сервера в KZ/RU
  или с компьютера владельца.

### Будущие поставщики
Владелец сам находит сайты с открытыми прайсами (похожими на mc.ru) и присылает. На каждого — своя папка
`suppliers/<имя>/` со своим парсером, выход в тот же формат `catalog/<имя>.csv`. Цель — чтобы всё обновлялось само.

## Курс валют
`python3 scripts/rate.py RUB [ГГГГ-ММ-ДД]` — официальный курс Нацбанка РК (nationalbank.kz, доступен из облака),
кэш/история в `reference/rates.csv`. Реальный курс оплаты выше официального: спред задаётся в
`reference/pricing.json` → `fx_spread_pct` (пока 0 — уточнить у владельца по факту первых оплат).
Владелец раньше брал курс у JetLogistic — у них 5,00 ₸/₽ (2026-10-22), при официальном 5,48.

## Доставка
- `python3 scripts/delivery_jet.py Москва Алматы 1000 0.5` — сборный груз JetLogistic (живой запрос к их калькулятору).
  Разбор тарифа: `logistics/jetlogistic.md`. Для металла ≈ 300–330 ₸/кг магистраль — дорого, годится для мелких партий.
- Фура (FTL) Москва → Алматы: ориентиры в `logistics/tariffs.csv` (публичные тарифы перевозчиков, даты не всегда известны):
  ≈ 1,15–1,83 млн ₸ за 20 т (58–92 ₸/кг) — в 4–6 раз дешевле сборного груза.
- По Казахстану: `python3 scripts/freight_della.py` — реальные свежие сделки с della.kz, копятся в `logistics/della_kz.csv`,
  выводит медиану ₸/км по классам машин (фура 20 т ≈ 450–520 ₸/км на 2026-10-22).
- ATI.SU: средние ставки (`/webapi/public/priceline/v2/site/chart`) только по платной лицензии — без неё не брать.
  Della по России не работает (украинская компания).

## Поиск
`python3 scripts/find.py труба проф 40х20х2` — числа из запроса ищутся в наименовании/размере, слова — в разделе/наименовании;
некондиция и уценка — в конце списка; для труб/листа/круга/арматуры выводится масса и цена за метр (м²).
Зависимости: `pip install -r requirements.txt`.

## Обновление прайса (план)
Скрипт скачивает xlsx → сохраняет в raw (если изменился) → парсер → проверки
(падение числа строк >20%, пропавшие колонки, скачок цены >30% — НЕ перезаписывать, слать тревогу) →
полная перезапись `catalog/<поставщик>.csv` → коммит → отчёт об изменениях цен.
